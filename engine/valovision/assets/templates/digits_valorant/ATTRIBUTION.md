# Real VALORANT HUD digit glyphs

Binary glyphs of the in-game HP font (1920x1080 capture, ~33 px tall), taken from
[Hussbyte101/pixel-hearts-overlay](https://github.com/Hussbyte101/pixel-hearts-overlay)
(`templates/0.png` … `templates/9.png`), MIT License, Copyright (c) 2026 Huss.
The font itself is part of the VALORANT HUD (Riot Games).

Used as the default digit set (`"digit_set": "digits_valorant"` in the layout).
The `digits/` folder holds DejaVu glyphs, kept only for unit tests of the reader.
